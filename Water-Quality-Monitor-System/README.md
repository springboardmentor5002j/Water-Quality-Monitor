# 💧 Water Quality Monitoring System

This project helps users monitor water quality, view nearby water stations,
receive alerts, and report water issues in their area.

## 🚀 Features
User authentication (Login & Register)
Map view of nearby water stations
Water quality readings
Verified user reports
Alerts based on water quality
Historical data visualization
Role-based access (Citizen / NGO / Admin)


## 🛠️ Tech Stack
### Frontend
React.js
Tailwind CSS
Leaflet (Maps)

### Backend
FastAPI
SQLAlchemy
PostgreSQL / SQLite
